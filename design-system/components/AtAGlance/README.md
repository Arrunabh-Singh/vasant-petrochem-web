# AtAGlance

The three values that decide a purchase, directly under a product hero: the label in `label` capitals, the value in `mono`.

- **Props**: `specs`, the catalog's spec list. The first three are shown, so order each product's specs with the deciding values first.
- **Phone**: three rows, label left and value right. **Laptop**: three columns divided by `line` rules, values at `spec-large` (20px).
- **It is data, not decoration**: never a giant number, never a gradient, never a value that is not in the catalog.
