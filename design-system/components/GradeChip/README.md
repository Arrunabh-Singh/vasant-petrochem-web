# GradeChip

The product's grade code (`SN-500`, `VG-30`) in mono on a quiet gold chip: `gold-ink` on `gold-tint` (5.4:1) inside a `gold-deep` hairline.

- **Props**: `code`, exactly as the catalog has it; `tone="quiet"` for the code in `gold-ink` with no chip, in tables and the local nav.
- **Use** one per product mention: beside the product name in heroes and cards.
- **Don't** put anything but a grade code in it, and don't recolour it per product (the drop already carries the product's colour).
