# Drops

One standalone SVG per product (100 × 176.26 view box, hex colours only), made by `Vasant.dropMarkup(tint, { plain: true })`, for ad tools, decks and print. Each carries its product's name as its accessible label.

| File | Product | Tint |
| --- | --- | --- |
| `drop-base-oil-sn150.svg` | Base Oil SN150 | straw |
| `drop-base-oil-sn500.svg` | Base Oil SN500 | gold (the logo's own) |
| `drop-rubber-process-oil.svg` | Rubber Process Oil | amber |
| `drop-light-diesel-oil.svg` | Light Diesel Oil | brown |
| `drop-industrial-fuel-oil.svg` | Industrial Fuel Oil | fuel |
| `drop-paving-bitumen-vg30.svg` | Paving Bitumen VG-30 | bitumen |
| `drop-mineral-turpentine-oil.svg` | Mineral Turpentine Oil | clear, with chrome rim |
| `drop-petroleum-jelly.svg` | Petroleum Jelly | white, with chrome rim |

The tints are illustrative, not colour specifications. Never change a drop's fill level, crop it, or set text on it.
